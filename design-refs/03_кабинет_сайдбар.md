# Задача: редизайн сайдбара личного кабинета

Прочитай референс целиком: `design-refs/theatre_account_profile_redesign.html`
(нужна только ЛЕВАЯ колонка референса — сайдбар; правую часть в этой задаче
не трогаем). Дизайн-система и запреты — в CLAUDE.md.

Найди компонент личного кабинета — модалка с аватаром, навигацией
«Личные данные / Контакты / Социальные сети / Уведомления / Мои билеты /
Мои спектакли» и кнопкой «Выйти» (вероятно ProfileModal / AccountModal /
UserCabinet). Перед правками покажи, какой файл нашёл.

## Концепция: профиль = карточка абонемента зрителя

1. Верх сайдбара — бордовая карточка ($stub-burgundy #4a1414):
   - Аватар: 54px круг. Если есть фото — фото; если нет — буква имени
     var(--font-display) italic 20px на фоне #2a0d0d.
     Бордер 1.5px rgba(243,231,220,0.4).
   - Имя 14px #f3e7dc, под ним email 11px #d9a89a
   - Лейбл «Зритель с {ГОД}» — 9px/2px/uppercase #b07a6c.
     Год = год регистрации пользователя (creationTime из Firebase auth
     metadata или первая бронь). Если данных нет — не выводить строку.
     Добавить FR-вариант: «Spectateur depuis {ГОД}».
   - Декоративный штрихкод (см. CLAUDE.md), цвет $cream, высота 16px
   - Снизу карточки два полукруглых «выреза» 14px цвета фона сайдбара
     (#1c1916) по углам — намёк на отрывную линию (aria-hidden)

2. Навигация — БЕЗ пилюль-подсветок:
   - Пункт: 13px, паддинг 9px 18px, border-left 2px transparent
   - Активный: цвет #f3e7dc, border-left 2px var(--accent)
   - Неактивные: #9c938a, при hover — #f3e7dc
   - Иконки у пунктов УБРАТЬ (сейчас слева иконки) — только текст
   - У «Мои билеты» счётчик активных броней: var(--font-mono) 10px
     var(--accent), просто цифра без кружка-бейджа
   - Эмодзи, если встретятся, заменить по правилам CLAUDE.md

3. «Выйти»: прижат к низу, отделён бордером 0.5px сверху,
   11px/1.5px/uppercase #6e675f, при hover #f3e7dc.
   Иконку двери заменить на текст «Выйти ↗».

4. Мобильная версия: сайдбар складывается как сейчас (не ломать
   текущее мобильное поведение); бордовая карточка на мобиле —
   горизонтальная (аватар слева, имя/email справа), штрихкод скрыть.

## Не трогать
- Контент правой части (вкладки) — отдельные задачи
- Логику переключения вкладок, signOut, данные пользователя

## Проверка
- Все вкладки переключаются, активная подсвечена красной чертой
- Счётчик броней показывает реальное число
- npm run build без ошибок
