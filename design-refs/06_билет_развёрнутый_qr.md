# Задача: редизайн развёрнутого билета с QR-кодом

Прочитай референс целиком: `design-refs/theatre_ticket_expanded_qr_paper_design.html`
Дизайн-система и запреты — в CLAUDE.md.

Меняем развёрнутое состояние билета во вкладке «Мои билеты»
(то, что появляется по клику на бронь: QR-код, детали, скачать PDF).

## Концепция: при разворачивании «отрывается» бумажная часть билета

Структура развёрнутой карточки сверху вниз:

1. Тёмная шапка (как свёрнутая карточка из задачи 05, но без корешка):
   название italic 18px + строка «дата · время · состав · цена»;
   справа штамп статуса + под ним «Свернуть ↑» 10px/1.5px/uppercase #9c938a.
   Два бейджа статуса («оплата на месте» + «не оплачено») схлопнуть
   в ОДИН штамп по правилам задачи 05.

2. Горизонтальная линия отрыва: пунктир 2px dashed rgba(243,231,220,0.25)
   с отступами 14px по бокам + два круглых выреза 20px цвета фона страницы
   слева и справа (aria-hidden).

3. Бумажная часть — фон $paper #f3e7dc (НЕ белый), тёмный текст $paper-ink:
   - Слева: QR-код на подложке #fdfaf6, радиус 14px, паддинг 12px.
     Фейковый SVG из референса НЕ копировать — использовать реальный QR.
     Если в проекте уже есть генерация QR — переиспользовать с цветами
     bgColor="#fdfaf6" fgColor="#241a16". Если нет —
     npm install qrcode.react и <QRCodeSVG value={ticketCode} size={128}
     bgColor="#fdfaf6" fgColor="#241a16" />.
     Под QR подпись 9px/2px/uppercase #8a7568:
     «Предъявите при входе» / «À présenter à l'entrée».
   - Справа: лейбл «Théâtre Tête-à-Tête» 10px/2px/uppercase цветом #a33b2e;
     детали строками на разделителях rgba(42,33,28,0.15):
     Дата / Время / Адрес / Билеты (значения #241a16, цена italic);
     ниже КОД БРОНИ: лейбл 9px + код var(--font-mono) 22px letter-spacing 3px
     #241a16, рядом декоративный штрихкод цвета $paper-ink высотой 26px;
     внизу «Скачать PDF» — текстовая ссылка 10px/1.5px/uppercase #8a7568
     с нижним подчёркиванием rgba(138,117,104,0.4) и IconDownload 12px.
     Большую кнопку-бокс «СКАЧАТЬ PDF» убрать.
   - Поле «CODE …» (большой тёмный бокс с кодом) убрать — код теперь
     на бумаге.

4. Анимация разворачивания: если уже есть — сохранить механизм;
   если делается через высоту, обернуть бумажную часть в
   Framer Motion AnimatePresence (initial/exit height: 0, opacity: 0,
   duration 0.35, ease easeOut). Не ломать существующий стейт
   развёрнуто/свёрнуто.

5. Адаптив: на мобиле QR и детали складываются в колонку, QR по центру.

## Не трогать
- Генерацию PDF, данные брони, логику клика
- Свёрнутое состояние (сделано в задаче 05)

## Проверка
- QR сканируется телефоном (тёмные модули на светлом фоне)
- «Скачать PDF» работает как раньше
- RU и FR
- npm run build без ошибок
