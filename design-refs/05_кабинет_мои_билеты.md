# Задача: редизайн вкладки «Мои билеты» в кабинете

Прочитай референс целиком: `design-refs/theatre_account_my_tickets_redesign.html`
Дизайн-система и запреты — в CLAUDE.md.

Меняем ТОЛЬКО контент вкладки «Мои билеты» (свёрнутый список броней).
Развёрнутое состояние с QR — следующая отдельная задача, его пока не трогать
(клик по билету продолжает разворачивать как сейчас).

## Концепция: каждая бронь — мини-билет с корешком

1. Заголовок вкладки: «Мои билеты» var(--font-display) italic 24px.

2. Карточка брони (свёрнутая): флекс-ряд, фон #1c1916,
   бордер 0.5px rgba(255,255,255,0.1), радиус 6px, overflow hidden.

   Левый корешок 96px:
   - Фон: для подтверждённой брони $stub-burgundy #4a1414,
     для ожидающей оплаты #3a2f14
   - Число дня: var(--font-display) italic 26px #f3e7dc
   - Под ним «июл · 20:00»: 10px/1.5px/uppercase,
     цвет #d9a89a (бордовый корешок) или #cdb27a (янтарный)
   - Внизу декоративный штрихкод высотой 14px цвета $cream
   - Перфорация по правому краю корешка: пунктир 2px dashed
     rgba(243,231,220,0.3) + вырезы 14px цвета фона страницы
     сверху и снизу (aria-hidden)
   - Месяц форматировать через i18n (RU/FR)

3. Правая часть карточки:
   - Название var(--font-display) italic 17px
   - Штамп статуса справа от названия:
     confirmed → «ПОДТВЕРЖДЕНО» / «CONFIRMÉ» ($stamp-green)
     pending + bank_transfer → «ОЖИДАЕТ ОПЛАТЫ» / «EN ATTENTE» ($stamp-amber)
     pending + on_site → «ОПЛАТА НА МЕСТЕ» / «SUR PLACE» ($stamp-amber)
     Углы поворота чередовать: +4deg, −3deg, +2deg… (по индексу в списке)
   - Строка состава: «1 × Стандарт · 30 €», цена var(--font-display) italic
   - Нижняя строка: код брони var(--font-mono) 13px letter-spacing 2px
     слева; справа контекстное действие 10px/1.5px/uppercase:
     confirmed → «Показать на входе →» (#9c938a)
     ожидает оплаты → «Реквизиты для перевода →» (#cdb27a)
     (это просто текст-указатель, клик по всей карточке работает как раньше)

4. Блок лояльности из этой вкладки УБРАТЬ ПОЛНОСТЬЮ — он переезжает
   во вкладку «Мои спектакли» (задача 07). Если в референсе он есть внизу —
   игнорировать эту часть референса.

## Не трогать
- Логику загрузки броней, сортировку, клик-разворачивание
- Развёрнутое состояние билета (следующая задача)

## Проверка
- Статусы и цвета корешков соответствуют реальным статусам броней
- RU и FR
- npm run build без ошибок
