## Компоновка — сохранить текущую

Двухколоночная сетка остаётся как есть: слева шапка спектакля → тип билета →
количество с итогом; справа телефон → способ оплаты → комментарий → кнопка
на всю ширину. Никаких перестановок блоков.

## Что поменять (отделка)

1. Шапка спектакля (бордовая панель #4a1414, $stub-burgundy):
   название курсивом var(--font-display) italic 17px, под ним дата
   var(--font-mono) 10px letter-spacing 1.5px цветом #d9a89a.
   Убрать из ПРАВОЙ колонки дубль названия спектакля — там остаётся только
   лейбл «Бронирование» (10px/2px/uppercase) + красная черта 40×2px под ним.

2. Тип билета: убрать красную обводку активной карточки.
   Активная: фон #26211c, бордер 0.5px rgba(243,231,220,0.16),
   радиус 16px, слева красная точка 13px (заполненный круг var(--accent)),
   цена справа var(--font-display) italic 19px.
   Неактивная: прозрачный фон, прозрачный бордер, opacity 0.55,
   кружок 13px с бордером 1.5px rgba(255,255,255,0.35).
   Клик по карточке выбирает тип (логика выбора уже есть — не менять).

3. Блок «Количество»: строку «Свободно мест: N из M» убрать,
   вместо неё в строке заголовка справа мелкий текст
   var(--font-mono) 10px #6e675f: «свободно N / M».
   Степпер: две круглые кнопки 34px (border-radius 50%,
   бордер 0.5px rgba(243,231,220,0.25), фон transparent),
   цифра между ними var(--font-display) italic 20px.
   Итого справа: лейбл 9px/2px/uppercase + сумма var(--font-display)
   italic 28px. Строку «15 € × 1 = 15 €» удалить.

4. Телефон и комментарий: фон #26211c, бордер 0.5px rgba(243,231,220,0.16),
   радиус 16px, паддинг 13px 17px. Фокус: бордер var(--accent).

5. Способ оплаты: две карточки рядом (как сейчас), но:
   активная — фон #26211c + красная точка 13px в правом верхнем углу
   (НЕ красная обводка); неактивная — opacity 0.55, прозрачный фон,
   пустой кружок в углу. Эмодзи 🏠 и 🏦 заменить на иконки из
   @tabler/icons-react: IconBuildingBank и IconTransfer (size 16, stroke 1.5).
   Если пакет не установлен — npm install @tabler/icons-react.

6. Кнопка подтверждения: на всю ширину, радиус 18px,
   текст слева, стрелка → прижата вправо (justify-content: space-between),
   letter-spacing 2.5px.

7. Блок лояльности (loyaltyBlock) — сохранить функциональность полностью,
   стилистически привести к системе: фон #26211c, радиус 16px,
   бордер 0.5px кремовый.
