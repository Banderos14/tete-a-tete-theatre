# Задача: редизайн вкладки «Мои спектакли» + перенос лояльности

Прочитай референс целиком: `design-refs/theatre_account_my_shows_loyalty_redesign.html`
Дизайн-система и запреты — в CLAUDE.md.

Меняем ТОЛЬКО контент вкладки «Мои спектакли».

## Что сделать

1. Заголовок: «Мои спектакли» var(--font-display) italic 24px.

2. Блок лояльности — НАВЕРХУ вкладки (переносим сюда из «Мои билеты»,
   если задача 05 уже выполнена — там его уже нет; используем тот же
   loyaltyService / данные, что использовались раньше):
   - Контейнер: фон #241a16, бордер 0.5px rgba(243,231,220,0.12),
     радиус 20px, паддинг 20px 22px
   - Верхняя строка: «Вы посетили N спектаклей» (N — var(--font-display)
     italic 18px) слева, лейбл «Лояльность» 11px/1.5px/uppercase справа
   - Прогресс — ряд «театральных кресел»: див 26×18px,
     border-radius 4px 4px 9px 9px. Заполненные — var(--accent),
     пустые — прозрачные с бордером 1px rgba(243,231,220,0.25).
     Количество кресел = порог следующей награды (из логики лояльности),
     заполненных = текущий прогресс. role="img" +
     aria-label="Прогресс лояльности: N из M посещений".
   - Подпись снизу 12px #9c938a: динамическая из текущей логики
     (например «следующая скидка 50% — после 10-го посещения»;
     если подарок доступен — текущий текст о доступном подарке).
   - FR-варианты всех строк.

3. Список посещённых спектаклей — строки на разделителях
   0.5px rgba(255,255,255,0.08) (НЕ карточки-коробки):
   - Слева миниатюра 44px радиус 14px: если у спектакля есть афиша —
     изображение (object-fit cover); если нет — цвет show.palette
     и инициалы названия var(--font-display) italic.
   - Название italic 16px, под ним дата+время 11px #9c938a.
   - ВАЖНО — группировка повторов: одинаковый спектакль, посещённый
     несколько раз, выводится ОДНОЙ строкой. В подписи к дате добавить
     «· были N раза/раз» цветом #cdb27a (правильное склонение:
     2–4 → «раза», 5+ → «раз»; FR: «· N fois»). Дату показывать последнюю.
   - Справа штамп «ПОСЕЩЕНО» / «VU» ($stamp-green, радиус 6px),
     для сгруппированных — «ПОСЕЩЕНО ×N». Углы чередовать (+3, −4, +2…).
   - Зелёные пилюли-бейджи «ПОСЕЩЕНО» (текущие) убрать.

4. Серый кружок-плейсхолдер прогресса (5 пустых кружков под текстом
   «Вы посетили…») — убрать, его заменяют кресла.

## Не трогать

- Другие вкладки

## Проверка

- Кресла соответствуют реальному прогрессу
- npm run build без ошибок
