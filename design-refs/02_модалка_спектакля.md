# Задача: редизайн модалки спектакля (детали + карусель афиш)

Прочитай референс целиком: `design-refs/theatre_show_modal_programme_spread_v2.html`
Дизайн-система и запреты — в CLAUDE.md.

Найди компонент модалки деталей спектакля — он рендерит возрастной ценз («0+»),
строки «ДАТА / НАЧАЛО / ДЛИТЕЛЬНОСТЬ / СТОИМОСТЬ», описание и кнопку
«КУПИТЬ БИЛЕТ», плюс карусель афиш слева (вероятно ShowModal / ShowDetailsModal
или похожее имя). Перед правками покажи мне, какой файл нашёл.

## Концепция: разворот театральной программки

Три зоны слева направо:
1. Афиша на вылет (250px) — БЕЗ рамок и паспарту, изображение до краёв
2. Вертикальный «корешок» (34px)
3. Контентная страница

## Что сделать

1. Левая зона — карусель:
   - Текущая афиша заполняет зону целиком (object-fit: cover).
     В референсе зелёный блок с текстом — это ПЛЕЙСХОЛДЕР, использовать
     реальные изображения из данных спектакля, логика карусели не меняется.
   - Стрелки ‹ › : круглые 32px, фон rgba(20,18,16,0.55), без бордера,
     поверх афиши по краям.
   - Миниатюры: полоса ВНИЗУ ПОВЕРХ афиши, фон rgba(16,14,12,0.55),
     миниатюры 34×24px радиус 6px; активная — бордер 1.5px var(--accent),
     неактивные — opacity 0.6. Отдельного ряда миниатюр ПОД афишей быть
     не должно. Дату/время под афишей не выводить.

2. Корешок (34px): вертикальный текст writing-mode: vertical-rl,
   var(--font-mono) 9px, letter-spacing 3px, uppercase, цвет #6e675f,
   текст: «Сезон 2025 / 2026 · Théâtre Tête-à-Tête · Nice».
   Бордеры слева и справа 0.5px rgba(255,255,255,0.08), фон #17140f.
   На мобиле корешок скрыть (display: none в mixins.mobile).

3. Контентная страница:
   - Возрастной ценз: ШТАМП в правом верхнем углу — бордер 2px var(--accent),
     цвет var(--accent), радиус 6px, rotate(7deg). Красную пилюлю-бейдж убрать.
   - Эйбрау (труппа · жанр): 10px/2px/uppercase #9c938a
   - Название: var(--font-display) italic 26px
   - Под названием красная черта 44×2px
   - Детали: строки «лейбл слева — значение справа» на разделителях
     0.5px rgba(255,255,255,0.1) (как сейчас, сохранить).
     Стоимость — var(--font-display) italic 16px.
   - Описание: буквица — первая буква var(--font-display) italic 42px,
     float left. Реализовать через CSS ::first-letter на параграфе
     (НЕ через отдельный span, чтобы работало с i18n).
     Описание свёрнуто до ~4 строк (line-clamp), ссылка «читать дальше»
     (#9c938a, underline, offset 3px) раскрывает полностью.
     Новые строки «читать дальше / свернуть» добавить в RU и FR словари.
   - Низ: кнопка «КУПИТЬ БИЛЕТ →» радиус 22px, паддинг 13px 28px +
     рядом текст «Осталось N мест» (11px #9c938a, число цветом #cdb27a).
     N взять из суммы available по ticketTypes.
